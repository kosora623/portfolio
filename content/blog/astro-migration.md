　このサイトはこれまで Next.js（静的書き出し）で作っていましたが、Astro に作り直しました。あわせて、このブログも始めます。

## なぜ移行したのか

　このサイトは作品を並べるだけのほぼ静的なページで、サーバーで動く機能はありません。それなのに、ページの大部分をブラウザ側の JavaScript で描画していたため、HTML を開いただけでは中身が空で、ページのタイトルや説明文も出ていませんでした。

　Astro は基本的に HTML を書き出し、必要な部分だけ JavaScript を動かす作りなので、こういうサイトには合っていると考えました。

## やったこと

- 作品ページ（`content/works/*.md`）はそのまま使い、表示を Astro のコンテンツコレクションに移した
- YouTube・ニコニコ動画・bilibili の URL を書いた段落は、ビルド時に埋め込みプレーヤーに変換するようにした
- 各ページに `<title>` や OGP を付けた
- ブログ（このページ）を追加した

## これから

　見た目はまだ以前のものを引き継いでいるので、次はデザインを作り直す予定です。作品が増えても見やすい一覧にしたいと思っています。
